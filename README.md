# دفتر جمعية كادي

تطبيق Android باللغة العربية لإدارة اشتراكات الجمعية.

## الوظائف الحالية
- إضافة عضو: الاسم واللقب ورقم الهاتف.
- 12 شهرًا من جانفي إلى ديسمبر.
- الاشتراك الشهري ثابت: 1000 دج.
- تسجيل الدفع لكل شهر.
- حساب إجمالي المدفوع والمتبقي.
- البحث بالاسم أو رقم الهاتف.
- واجهة عربية RTL.

## البناء
افتح المشروع في Android Studio، ثم اختر:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

ملف APK الناتج سيكون عادة داخل:
app/build/outputs/apk/debug/app-debug.apk

> ملاحظة: هذه النسخة الأولى تحفظ البيانات أثناء تشغيل التطبيق فقط. النسخة التالية يمكنني تطويرها بحفظ دائم داخل الهاتف، وتعديل/حذف الأعضاء، وتقارير وإجمالي الجمعية.
