# دفتر جمعية كادي
مشروع Android أولي — الاشتراك الشهري 1000 دج.

## بناء APK عبر GitHub Actions
ارفع هذا المشروع إلى مستودع GitHub، ثم من تبويب Actions شغّل "Build APK".
بعد نجاح البناء، افتح نتيجة الـworkflow ونزّل artifact باسم `daftar-jam3iya-kadi-apk`.

> ملاحظة: يجب أن يحتوي المشروع على Gradle Wrapper (`gradlew` و`gradle/wrapper/...`) لكي يعمل البناء مباشرة.
